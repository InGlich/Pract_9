# Домашнее задание к работе 9

## Условие задачи
**Написать программу, выводящую на экран заданную геометрическую фигуру, нарисованную с помощью заданного с клавиатуры символа. Предусмотреть возможность изменения размеров фигуры путем задания ее параметров пользователем.**

**Вариант 2: Два квадрата** (с заполнением контура)

Параметры фигуры:
- Сторона 1 (верхний левый квадрат)
- Сторона 2 (белый центральный квадрат)  
- Сторона 3 (нижний правый квадрат)

---

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. **Ввод данных:**
   - Считать символ для рисования
   - Считать сторону 1 (верхний левый квадрат)
   - Считать сторону 2 (белый квадрат)
   - Считать сторону 3 (нижний правый квадрат)
3. **Вычисление размеров:**
   - Общая ширина = сторона 1 + сторона 3 - сторона 2
   - Общая высота = сторона 1 + сторона 3 - сторона 2
4. **Цикл по строкам (повторение):**
   - Для каждой строки i от 0 до высота-1:
     - Цикл по столбцам j от 0 до ширина-1:
       - Проверить принадлежность точки (i,j) к первому квадрату
       - Проверить принадлежность точки (i,j) ко второму квадрату
       - Проверить принадлежность точки (i,j) к белому квадрату
       - Если в белом квадрате → вывести пробел
       - Иначе если в одном из квадратов → вывести символ
       - Иначе → вывести пробел
     - Переход на новую строку
5. **Конец**

## 2. Реализация программы

```c
int DZ(char symbol, int s1, int s2, int s3) {
    int width = s1 + s3 - s2;
    int height = s1 + s3 - s2;

    printf("\n");
    for (int i = 0; i < height; i++) {
        for (int j = 0; j < width; j++) {
            int in1 = (i < s1&& j < s1);
            int in2 = (i >= s2 && i < s2 + s3 && j >= s2 && j < s2 + s3);
            int inWhite = (i >= s1 - s2 && i < s1&& j >= s1 - s2 && j < s1);

            if (inWhite) {
                printf("  ");
            }
            else if (in1 || in2) {
                printf("%c ", symbol);
            }
            else {
                printf("  ");
            }
        }
        printf("\n");
    }
    return 0;
}
```
